# Privacy Policy / プライバシーポリシー（Cairnwatch Uploader）

Last updated / 最終更新: 2026-11-25

## 日本語

Cairnwatch Uploader は YouTube API サービスを使います。使う人は YouTube の利用規約（https://www.youtube.com/t/terms ）に同意したものとします。Google のプライバシーポリシーは https://policies.google.com/privacy です。

このツールを使うのは、YouTube チャンネル「Cairnwatch」の持ち主だけです。持ち主が許可した自分のチャンネルに、動画とサムネを上げて予約するためだけに YouTube のデータを使います。

許可の情報（トークン）は持ち主のパソコンの中だけに保存し、ほかの人や会社には渡しません。

許可は https://myaccount.google.com/permissions からいつでも取り消せます。取り消した時は、パソコンに保存したトークンも消します。

連絡はこのリポジトリの Issues からどうぞ。

## English

Cairnwatch Uploader uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service (https://www.youtube.com/t/terms ). Google Privacy Policy: https://policies.google.com/privacy

The tool is used only by the owner of the YouTube channel "Cairnwatch". It uses YouTube data only to upload videos and thumbnails to, and schedule them on, the owner's own channel with the owner's permission.

The access token is stored only on the owner's computer and is never shared with any other person or company.

You can revoke access at any time at https://myaccount.google.com/permissions . When access is revoked, the stored token is deleted from the computer as well.

Contact: please open an issue in this repository.
